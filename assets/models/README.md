# Optional avatar

The model is not supplied and the module is disabled. Add an authorised `avatar.glb` without Draco/KTX2 compression, then enable `avatar.enabled` in `_config.yml`. A self-contained GLB with embedded textures avoids external paths. The local loader, framing and static render are included. Check the licence, file size and result on mobile. The avatar is decorative; the identity remains available in text.
